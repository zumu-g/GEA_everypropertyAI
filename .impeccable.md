# Impeccable — PropertyIQ

## Design Context

### Users
Real estate professionals (and prospective buyers/owners) in Casey & Cardinia, Victoria,
looking up a property to get a fast, trustworthy read on its data: stats, value estimate,
sale/rental history, comparables, planning risk, schools/transport. Used on desktop and
mobile, often mid-conversation or mid-appraisal — they need answers in seconds.

### Brand Personality
Precise · trustworthy · quietly authoritative. A property **data product** (PropTrack /
CoreLogic / Stripe / Linear register), not a marketing brochure. A GEA (Grants Estate
Agents) product, so a single gold accent ties it back to the brand — used sparingly.

### Aesthetic Direction
Cooler & whiter than the GEA editorial baseline (intentional override, see DESIGN.md).
Sans-dominant typography, hairline rules over shadows, generous cool whitespace,
monospaced figures for all data. Light theme — users view this in daylight work contexts
and the data must read crisp and calm. Anti-references: rainbow dashboards, glassmorphism,
SaaS-blue, gradient text, card-in-card nesting.

### Design Principles
1. **Space communicates structure** — tight within a data group, generous between sections.
2. **Hairlines, not shadows** — surfaces are delineated by 1px rules and whitespace.
3. **One accent** — gold for brand moments, steel-blue (`--color-data`) for data/charts; never both competing.
4. **Figures are monospaced + tabular** — precision is the brand.
5. **Density matches content** — this is a data surface; comfortable but information-rich, not airy marketing.

> Tokens, type scale, and the GEA override are defined in `DESIGN.md`. Honour them.
